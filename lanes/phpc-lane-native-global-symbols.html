2026-05-21

Implemented:

  • Extended the bounded native function-scope imported-global slice to integer

    • root seeds and integer literal writes. The runtime ABI now exposes phpc_native_value_from_scalar(NativeScalarValue), letting generated LLVM IR and C native executable sources turn the existing scalar ABI into owned NativeValueHandles before storing them in the linked root symbol table. The covered smoke global $x; $x = 42; echo $x; now writes through NativeFunctionFrameHandle, echoes the imported value from the frame, and propagates the final known integer to a subsequent top-level echo $x. Non-integer scalar writes, dynamic/global-array shapes, parameters/defaults, returns, recursion, broader root synchronization, undefined-root diagnostics, references/COW, includes, multiple globals, and general function-call lookup remain explicit blockers.

  • Extended the bounded native function-scope global recognizer from a single

    • optional string write before one echo into an ordered same-global action list. The newly covered smoke global $x; echo $x; $x = "changed"; echo $x; still requires a zero-argument, non-nested function and one direct imported name, but generated LLVM IR and C native executable sources now perform read/write/read through the same NativeFunctionFrameHandle and linked root symbol table. This proves the imported root slot remains live across multiple operations in one native frame. For the same exact string-write subset, zero-argument calls now also propagate the final known imported-global value back into subsequent straight-line top-level lowering, so update_global(); echo $x; observes the string literal written inside the generated callee. Parameters/defaults, returns, recursion, broader post-call root synchronization, non-string writes, undefined-root diagnostics, references/COW, includes, dynamic globals, multiple globals, and general function-call lookup remain explicit blockers.

  • Extended the bounded native function-scope global slice from read-only

    • global $x; echo $x; to the next exact write-through smoke: global $x; $x = "changed"; echo $x;. The LLVM IR and C-backed native executable generators now recognize zero-argument, non-nested functions with that exact body shape, import the root slot through NativeFunctionFrameHandle, write the string literal via phpc_native_function_frame_write_variable, read it back through the same frame, and echo through the runtime value helper. Focused ABI tests cover both emitters, and broader function frames, parameters/defaults, returns, recursion, non-string writes, undefined-root diagnostics, references/COW, includes, dynamic globals, multiple globals, and general call lookup remain explicit native lowering blockers.

  • Added the first bounded linked native executable path:

    • phpc compile <input.php> --emit-exe <output> now emits C for the current straight-line native subset, builds php_runtime as a static library, links with cc, and writes an executable. Direct compile-time string output on this path routes through phpc_native_string_from_bytes, phpc_native_value_from_string_with_diagnostic, and phpc_native_value_echo_stdout rather than direct printf. phpc_native_value_echo_stdout now flushes stdout after successful writes so C-linked native executables expose runtime-owned output before exit. Focused tests prove the generated C helper calls and execute a linked binary against tests/fixtures/milestone2300/native_link_runtime_helper.php. This is not a broad native support claim: dynamic string-pointer helper lowering remains LLVM-IR-only, and arrays, objects, functions, references, request/session/stream/header state, exceptions, includes, and broad PHP coercions remain unsupported or bounded by existing native diagnostics.

  • Extended the native array runtime ABI beyond empty/len/free. Native array

    • handles can now append scalar values, append clones of existing NativeValueHandle values, and read integer-keyed slots as new runtime-owned value handles. The deterministic native runtime IR probe declares phpc_native_array_append_scalar, phpc_native_array_append_value, and phpc_native_array_read_int, with a probe function that appends, reads, echoes, and frees the handles. Generated PHP array literals still reject in native lowering; this is ABI groundwork for future array lowering, not broad native array support.
